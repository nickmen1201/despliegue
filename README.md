# CardioRisk · Predicción de ataque al corazón

App de Streamlit que despliega un modelo de Regresión Logística (scikit-learn) para estimar el riesgo de ataque al corazón.

- `5_Clasificacion_ataque_corazon_corregido.ipynb`: entrenamiento, comparación de modelos y exportación a `modelo-class.pkl`.
- `app.py`: despliegue (predicción individual y por lotes desde CSV/Excel).

Ejecutar en local: `python -m streamlit run app.py`

> Herramienta académica; no sustituye el diagnóstico médico.
